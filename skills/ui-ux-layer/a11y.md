# ui-ux-layer · MÓDULO: a11y
_Accesibilidad · WCAG · Contraste · Screen readers · Keyboard navigation_
_Versión: 1.0 · 2026-05-21_

## CUÁNDO CARGAR ESTE MÓDULO
Apps comerciales · Apps móviles · Cualquier output que va a usuarios finales reales
En jurisdicciones donde la accesibilidad digital es requisito legal (USA: ADA, EU: EAA).

---

## PRINCIPIO RECTOR

La accesibilidad no es restricción — es diseño para el peor caso.
Un output accesible funciona para todos: usuarios con discapacidad, usuarios bajo el sol
con un teléfono brillante, usuarios mayores con fuente grande, usuarios rápidos con teclado.

**Regla:** Conformidad mínima WCAG 2.1 AA en todos los outputs comerciales.
**Regla:** Nunca sacrificar la marca por la accesibilidad — el diseño accesible puede ser hermoso.

## SECCIÓN A11Y-1 — CONTRASTE DE COLOR (WCAG AA)

### Ratios mínimos requeridos

```
WCAG AA (mínimo para apps comerciales):
  Texto normal  (<18px o <14px bold):  4.5:1
  Texto grande  (≥18px o ≥14px bold):  3:1
  Elementos UI  (bordes, íconos):       3:1

WCAG AAA (óptimo — apuntar a esto):
  Texto normal:  7:1
  Texto grande:  4.5:1
```

### Verificación de la paleta ForumPHs

```
Combinaciones que PASAN WCAG AA:
  Parchment (#F0EDE8) sobre Carbon Deep (#0E1018)    → ratio ~15:1 ✅ AAA
  Parchment (#F0EDE8) sobre Carbon (#1C2233)         → ratio ~11:1 ✅ AAA
  Parchment (#F0EDE8) sobre Amatista (#5C3472)       → ratio ~7.2:1 ✅ AAA
  Amatista Tint (#EAD9F5) sobre Carbon Deep          → ratio ~13:1 ✅ AAA
  Success (#4ADE80) sobre Carbon Deep                → ratio ~8:1 ✅ AAA

Combinaciones que REQUIEREN VERIFICACIÓN (pueden fallar):
  Stone (#6B6460) sobre Carbon (#1C2233)             → ~4.2:1 ⚠️ borderline AA
  Dust (#B8B0A8) sobre Carbon (#1C2233)              → ~6.8:1 ✅ OK
  Terra (#C4622D) sobre Carbon Deep (#0E1018)        → ~4.9:1 ✅ AA (pero justo)
  Amatista (#5C3472) sobre Parchment (#F0EDE8)       → ~7.1:1 ✅ AAA

Combinaciones que FALLAN WCAG AA:
  Stone (#6B6460) sobre Parchment (#F0EDE8)          → ~2.8:1 ❌ Evitar para texto
  Terra (#C4622D) sobre Parchment (#F0EDE8)          → ~3.4:1 ⚠️ OK para texto grande, NO para normal
```

**Herramientas de verificación:**
- Coolors Contrast Checker: `contrast.cool`
- WebAIM Contrast Checker: `webaim.org/resources/contrastchecker`
- Figma plugin: Stark o Able

```javascript
// Función de verificación en runtime (para generar tokens accesibles dinámicamente)
function getContrastRatio(color1Hex, color2Hex) {
  const lum1 = getLuminance(color1Hex);
  const lum2 = getLuminance(color2Hex);
  const lighter = Math.max(lum1, lum2);
  const darker  = Math.min(lum1, lum2);
  return (lighter + 0.05) / (darker + 0.05);
}

function getLuminance(hex) {
  const rgb = hexToRGB(hex);
  const [r, g, b] = rgb.map(c => {
    c /= 255;
    return c <= 0.03928 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4);
  });
  return 0.2126 * r + 0.7152 * g + 0.0722 * b;
}
```

```javascript
// Trap focus en modal — implementación correcta
function trapFocus(modal) {
  const focusable = modal.querySelectorAll(
    'a[href], button:not([disabled]), input:not([disabled]), select:not([disabled]), textarea:not([disabled]), [tabindex]:not([tabindex="-1"])'
  );
  const first = focusable[0];
  const last  = focusable[focusable.length - 1];
  
  modal.addEventListener('keydown', (e) => {
    if (e.key !== 'Tab') return;
    if (e.shiftKey) {
      if (document.activeElement === first) { e.preventDefault(); last.focus(); }
    } else {
      if (document.activeElement === last) { e.preventDefault(); first.focus(); }
    }
  });
  
  // Enfocar el primer elemento al abrir
  first.focus();
}

// Cerrar modal con Escape
modal.addEventListener('keydown', (e) => {
  if (e.key === 'Escape') closeModal();
});
```

## SECCIÓN A11Y-4 — ARIA ROLES Y LIVE REGIONS

```html
<!-- Live regions — para notificaciones que aparecen dinámicamente -->

<!-- Anuncios no urgentes (ej: "Informe generado correctamente") -->
<div role="status" aria-live="polite" aria-atomic="true" class="sr-only" id="status-msg">
</div>

<!-- Anuncios urgentes (ej: "Error: no se pudo subir el recibo") -->
<div role="alert" aria-live="assertive" aria-atomic="true" class="sr-only" id="alert-msg">
</div>

<!-- Para actualizar en JS -->
<script>
function announceToScreenReader(message, urgent = false) {
  const el = document.getElementById(urgent ? 'alert-msg' : 'status-msg');
  el.textContent = ''; // resetear para que el lector lo re-anuncie
  requestAnimationFrame(() => { el.textContent = message; });
}

// Uso: después de subir un recibo exitosamente
announceToScreenReader('Recibo procesado correctamente. Monto detectado: $380.00');
// Uso: en error
announceToScreenReader('Error al procesar el recibo. Intenta de nuevo.', true);
</script>

<!-- Expandibles / Accordions -->
<button
  aria-expanded="false"
  aria-controls="fase-i-detail"
  onclick="toggleSection(this)">
  Fase I — 3 unidades
</button>
<div id="fase-i-detail" hidden>
  <!-- contenido expandible -->
</div>

<!-- Progress bars accesibles -->
<div role="progressbar"
     aria-valuenow="75"
     aria-valuemin="0"
     aria-valuemax="100"
     aria-label="Procesando informe — 75%">
  <div style="width: 75%"></div>
</div>
```

## SECCIÓN A11Y-7 — REDUCCIÓN DE MOVIMIENTO

```css
/* SIEMPRE incluir este bloque en cualquier output con animaciones */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
  
  /* Skeleton — mostrar estado estático en lugar de shimmer */
  .skeleton {
    animation: none;
    background: rgba(92,52,114,0.1);
  }
  
  /* Transiciones de página — fade instantáneo */
  .page-transition { animation: none; opacity: 1; }
  
  /* Parallax — deshabilitar */
  [data-parallax] { transform: none !important; }
}
```

## SECCIÓN A11Y-8 — CHECKLIST DE AUDITORÍA

Antes de entregar cualquier app o output interactivo:

**Contraste:**
- [ ] Todo texto normal en ratio ≥ 4.5:1
- [ ] Todo texto grande en ratio ≥ 3:1
- [ ] Todos los elementos UI interactivos en ratio ≥ 3:1
- [ ] Stone sobre Carbon verificado (borderline)

**Semántica:**
- [ ] Un solo `<h1>` por página
- [ ] Jerarquía de headings sin saltar niveles
- [ ] Todos los botones con texto descriptivo
- [ ] Todos los inputs con `<label>` asociado
- [ ] Imágenes con `alt` apropiado

**Interacción:**
- [ ] Todos los elementos interactivos alcanzables con Tab
- [ ] Focus visible en todos los elementos focusables
- [ ] Modales con focus trap
- [ ] Escape cierra modales/drawers
- [ ] Skip link presente

**Screen reader:**
- [ ] Live regions para notificaciones dinámicas
- [ ] ARIA roles correctos donde corresponde
- [ ] Errores de formulario con `aria-describedby`

**Mobile:**
- [ ] Todos los touch targets ≥ 44px
- [ ] `prefers-reduced-motion` implementado
- [ ] Texto ≥ 11px en cualquier contexto
